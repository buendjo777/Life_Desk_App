# demo-vault

Invented data for Desk's Demo mode and the portfolio showcase. Every person, company,
programme, phone number and figure here is made up. **Never add real data.**

Demo "today" is pinned by `desk/settings.json` → `demo_today` (Wednesday 11 November 2026, 08:12).
`calendar/events.json` stands in for EventKit. `tutoring/` is committed here only because it is fake;
in the live vault it is gitignored.
